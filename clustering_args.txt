Clustering done on the data/Phosphosite_seq_fixed.fasta file, via MMseqs2, using the following arguments
--min-seq-id 0.3 -c 0 --cov-mode 1 --cluster-mode 2 --alignment-mode 3 -s 6 --single-step-clustering

-cluster_mode 2 is a CD-HIT-like greedy incremental approach.
-c 0 turns off coverage requirements, meaning we cluster only based on similarity, resulting in larger clusters. --cov-mode is not used.
--single-step-clustering turns off cascaded clustering
--alignment-mode 3 means that similarity is "defined as the number of identical aligned residues divided by the number of aligned columns including internal gap columns", according to the MMSeqs2 docs.
